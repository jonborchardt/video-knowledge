This notice confirms the grant categories and grant values as approved by the Secretary of State for the purposes of Regulation 13 of the Boiler Upgrade Scheme (England and Wales) Regulations 2022.

The grant categories and grant values, set out below, will be effective from 21 July 2026.

Approved Grant Categories - Set Three

A boiler upgrade grant for the installation of:

An air-to-water heat pump in a property that is not an off-gas grid property

An air-to-air heat pump in a property that is not an off-gas grid property

A ground source heat pump in a property that is not an off-gas grid property

An air-to-water heat pump in an off-gas grid property that is replacing a coal heating system

An air-to-water heat pump in an off-gas grid property that is replacing a liquefied petroleum gas heating system

An air-to-water heat pump in an off-gas grid property that is replacing an oil heating system

An air-to-water heat pump in an off-gas grid property that is replacing a fossil fuel hybrid system

An air-to-water heat pump in an off-gas grid property that is replacing an electric heating system that is not a heat pump

An air-to-water heat pump in an off-gas grid property that is replacing any other fossil fuel heating system that is not covered by row 4 to 8 of this Table

An air-to-air heat pump in an off-gas grid property that is replacing a coal heating system

An air-to-air heat pump in an off-gas grid property that is replacing a liquefied petroleum gas heating system

An air-to-air heat pump in an off-gas grid property that is replacing an oil heating system

An air-to-air heat pump in an off-gas grid property that is replacing a fossil fuel hybrid system

An air-to-air heat pump in an off-gas grid property that is replacing an electric heating system that is not a heat pump

An air-to-air heat pump in an off-gas grid property that is replacing any other fossil fuel heating system that is not covered by row 10 to 14 of this Table

A ground source heat pump in an off-gas grid property that is replacing a coal heating system

A ground source heat pump in an off-gas grid property that is replacing a liquefied petroleum gas heating system

A ground source heat pump in an off-gas grid property that is replacing an oil heating system

A ground source heat pump in an off-gas grid property that is replacing a fossil fuel hybrid system

A ground source heat pump in an off-gas grid property that is replacing an electric heating system that is not a heat pump

A ground source heat pump in an off-gas grid property that is replacing any other fossil fuel heating system that is not covered by row 16 to 20 of this Table

A biomass boiler in an off-gas grid property replacing a coal heating system

A biomass boiler in an off-gas grid property replacing a liquified petroleum gas heating system

A biomass boiler in an off-gas grid property replacing an oil heating system

A biomass boiler in an off-gas grid property replacing a fossil fuel hybrid system

A biomass boiler in an off-gas grid property replacing an electric heating system that is not a heat pump

A biomass boiler in an off-gas grid property replacing any other fossil fuel heating system that is not covered by row 22 to 26 of this Table
